# Speaknxxt - English Fluency & Public Speaking Landing Page

High-converting modern landing page for **Speaknxxt** (Instagram: [@speaknxxt](https://www.instagram.com/speaknxxt)), mentored by **Mentor Kunal**.

## Features
- **Apple Design Language**: Clean frosted glassmorphism, SF typography, responsive segmented controls, and continuous curvature cards.
- **Interactive Practice Hub**: Native Web Speech API Diction Trainer, Tongue Twister Drills, Daily Grammar Quiz, and Corporate Error Busters.
- **CEFR Fluency Assessment**: Interactive 5-step diagnostic quiz generating personalized WhatsApp reports.
- **Meta WhatsApp Business Flows**: Direct lead generation connected to WhatsApp Business messaging.
- **Mobile-First Responsive**: Custom sliding drawer navigation for all devices.

## Tech Stack
- Pure Semantic HTML5
- Vanilla CSS3 (Custom Apple Design System)
- Vanilla ES6 JavaScript (SpeechSynthesis API, Dynamic DOM, Event Delegation)
